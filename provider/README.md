# VK Music provider

В этой папке находится исходный код дополнительного Music Assistant provider для VK Music. Dockerfile переносит его в `music_assistant/providers/vk_music` внутри отдельного образа Music Assistant Server 2.10.9.

Реализованы поиск треков/исполнителей/альбомов/плейлистов, просмотр собственных плейлистов и треков коллекции, получение ссылки аудиопотока непосредственно перед воспроизведением. Реальная работа зависит от того, предоставляет ли VK доступ данному токену и конкретному треку.

Провайдер использует токен и User-Agent, введённые через setup flow Music Assistant. Не добавляй секреты в исходный код/CI и не включай сбор пароля, cookies или кодов подтверждения. Запрещён обход DRM, подписок и ограничений доступа.
